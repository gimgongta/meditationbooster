Meditation Booster

## 간단한 설명 (최대 80자)

```
재생 버튼 하나로 시작하는 1분 명상. 네 단계만 따라가면 됩니다.
```

## 자세한 설명 (최대 4000자)

```
조용한 곳에 앉아 재생 버튼을 누르면 1분 동안 벨소리가 흐릅니다.
소리에 온전히 집중하다가, 소리가 멈추는 순간 명상이 시작됩니다.

Meditation Booster는 명상을 처음 시작하는 분을 위한 아주 단순한 앱입니다.
설정할 것도, 고를 것도 없습니다. 화면에 적힌 네 단계를 그대로 따라가기만 하면 됩니다.

■ 이렇게 사용하세요
1. 조용한 곳에서 편안한 자세를 취합니다.
2. 재생 버튼을 누릅니다.
3. 눈을 감고 심호흡을 하며 온 몸과 정신을 소리에 집중합니다.
4. 소리가 멈추면 온 몸과 정신은 온전히 나에게 집중되며, 명상이 시작됩니다.

■ 이런 분께 권합니다
· 명상을 시작하고 싶지만 무엇부터 해야 할지 모르는 분
· 복잡한 기능이나 구독 없이 가볍게 쓰고 싶은 분
· 잠들기 전이나 일과 사이에 짧은 휴식이 필요한 분

■ 특징
· 회원가입과 로그인이 필요 없습니다.
· 기기 언어에 맞춰 한국어와 영어로 표시됩니다.
· 1분, 하루 한 번이면 충분합니다.

■ 이용 안내
· 콘텐츠를 불러오기 위해 인터넷 연결이 필요합니다.
· 본 앱은 의료기기나 치료 목적의 서비스가 아닙니다. 건강상의 문제가 있다면 전문가와 상담하세요.

개인정보처리방침: https://gimgongta.github.io/mb-privacy/
```
