# Play Console 등록용 에셋

`com.unumest.meditationbooster` (versionName 1.1.0 / versionCode 2) 의 스토어 등록정보에 쓰는 그래픽과 문구를 모아둔 폴더입니다.
스크린샷은 모두 실제 앱이 띄우는 화면(<https://gimgongta.github.io/mb-web>)을 안드로이드 모바일 에뮬레이션으로 캡처한 것입니다.

## 파일 목록

| 파일 | 크기 | Play Console 위치 |
| --- | --- | --- |
| `icon/play-store-icon-512.png` | 512×512, 32비트 PNG | 기본 스토어 등록정보 → 앱 아이콘 |
| `feature-graphic/feature-graphic-1024x500-ko.png` | 1024×500 | 기본 스토어 등록정보(한국어) → 그래픽 이미지 |
| `feature-graphic/feature-graphic-1024x500-en.png` | 1024×500 | 기본 스토어 등록정보(영어) → 그래픽 이미지 |
| `screenshots/phone/{ko,en}/*.png` | 1080×1920 (9:16) ×3 | 휴대전화 스크린샷 (최소 2장, 최대 8장) |
| `screenshots/tablet7/{ko,en}/*.png` | 1200×1920 ×3 | 7인치 태블릿 스크린샷 (선택) |
| `screenshots/tablet10/{ko,en}/*.png` | 1600×2560 ×3 | 10인치 태블릿 스크린샷 (선택) |
| `listing-ko.md`, `listing-en.md` | — | 앱 이름 / 간단한 설명 / 자세한 설명 |

모든 이미지가 Play 규격(아이콘 1MB 이하, 그래픽 이미지 15MB 이하, 스크린샷 8MB 이하·320~3840px·16:9~9:16)을 충족합니다.
태블릿 스크린샷은 필수가 아니지만, 올려두면 스토어에 "태블릿에 최적화되지 않음" 안내가 뜨지 않습니다.

### 데이터 보안(Data safety) 설문

앱이 선언한 권한은 `INTERNET` 하나뿐이고, 계정·저장소·위치·기기 식별자를 다루는 코드가 없습니다.
따라서 "데이터를 수집하거나 공유하지 않음"으로 답하면 됩니다. 단, 아래 두 가지는 직접 확인하세요.

- 앱은 WebView로 GitHub Pages에서 콘텐츠를 내려받습니다. GitHub의 표준 서버 로그(IP 등)는 보통 수집으로 선언하지 않지만, 이후 분석 도구나 광고 SDK를 넣으면 반드시 갱신해야 합니다.
- 전송 중 암호화: 콘텐츠를 HTTPS로만 불러오므로 "예".

## 등록 전에 확인할 것

- [ ] **메인화면 5번 항목("텍스트가 입체적으로 보인다면…") 삭제를 mb-web에 반영하고 배포하세요.** 이 폴더의 문구와 스크린샷은 이미 4단계 기준으로 만들어져 있습니다(캡처 시 해당 블록을 제거한 상태로 촬영). 배포 전에 스토어에 올리면 실제 앱과 스크린샷이 달라 심사에서 지적될 수 있으니, **웹 배포를 먼저 끝낸 뒤 등록정보를 제출**하세요.
- [ ] **개인정보처리방침의 연락처가 아직 `[연락 이메일]` 플레이스홀더입니다.** (mb-privacy 저장소 7번 항목) Play는 실제 연락 수단을 요구하므로 배포 전에 교체하세요.
- [ ] `android/keystore.properties` 의 업로드 키로 서명한 AAB (`./gradlew bundleRelease`) 준비 — 키와 비밀번호 백업 필수.
- [ ] 스토어 등록정보의 언어를 한국어/영어 둘 다 추가하고, 각 언어에 맞는 그래픽 이미지와 스크린샷을 올릴 것.
- [ ] 앱 이름(`Meditation Booster`)이 이미 등록된 다른 앱과 혼동되지 않는지 확인.

## 다시 만들려면

스크린샷은 실제 배포된 웹 화면을 캡처해 프레임에 합성한 것이라, 웹 화면(mb-web)이 바뀌면 다시 만들어야 합니다.
생성에 쓴 스크립트는 일회성 도구라 저장소에 포함하지 않았습니다. 화면이 바뀌면 Claude Code에 다시 요청하거나,
헤드리스 Chrome으로 `https://gimgongta.github.io/mb-web?lng=ko|en` 을 360×640 @3x(휴대전화), 600×960 @2x(7인치),
800×1280 @2x(10인치) 모바일 에뮬레이션으로 캡처해 같은 레이아웃에 넣으면 됩니다.
